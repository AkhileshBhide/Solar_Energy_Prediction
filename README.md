## Solar Energy Prediction
Project Title : 
Predicting Solar Energy Production Using a Feedforward Neural Network: A Comparison with Linear Regression 

Language : 
Python

Libraries Used : 
PyTorch, pandas, matplotlib, numpy, scikit-learn

Results: 
The study compared both models on the same test data and calculated RMSE on the standardized values. The linear regression model has an RMSE of 0.447, whilst the neural network has an RMSE of 0.347. This represents an approximate 22.4% improvement when going from a linear regression model to a neural network
